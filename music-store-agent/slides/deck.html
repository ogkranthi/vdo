The situation

Your agent worked in the demo.
Production is another story.

Visibility

You can't see failures

"The bot said something weird yesterday" — but which step went wrong? The model? A tool? The data? There's no flight recorder.

Measurement

You can't measure changes

Every prompt tweak is a leap of faith. Did it get better, or just different? Nobody can say without re-testing by hand.

Trust

You can't let it act

Refunds, account changes — real writes need controls a raw LLM loop doesn't have. So the agent stays a toy.

You can't fix what you can't see, and you can't ship what you can't measure.

The open-source stack

Three layers, one ecosystem

LangChain agent framework

Standard interfaces for models and tools, plus create_agent — a production agent loop with middleware for the cross-cutting concerns: auth, PII, limits, summarization.

LangGraph runtime

The durable engine underneath: state, streaming, persistence, and first-class human-in-the-loop interrupts — pause a run, get approval, resume. Infrastructure you'd otherwise build yourself.

Deep Agents architecture

The cognitive architecture the best agent teams converged on — planning, subagents, context isolation — prebuilt, as one function call.

LangSmith commercial

Eyes and measuring stick for all of it: tracing every run, evals scoring every change, Studio for visual debugging. The OSS builds the agent; LangSmith is how you operate it.

Why LangSmith

The engineering loop that makes it reliable

01 · Observe

Tracing

Every run recorded step by step: reasoning, tool inputs and outputs, latency, tokens, cost. Debugging becomes clicking, not guessing.

02 · Measure

Datasets & evals

Golden questions scored by an LLM judge and deterministic trajectory checks. Change the prompt or model — get a diff, not a feeling.

03 · Improve

Studio & feedback

Visual graph debugging, interactive runs, approval flows; annotation queues turn odd production runs into new test cases.

Each piece feeds the next: traces become datasets, datasets become scores, scores tell you what to fix.
